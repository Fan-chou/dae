安装 kdae 本地证书

面板使用路由器自己签发的证书。安装并信任下面的根证书后，Safari、Chrome 等浏览器即可正常打开 HTTPS 面板，不再出现警告，且可使用离线缓存与“添加到主屏幕”。证书私钥只保存在路由器上。

iPhone / iPad / Mac：下载描述文件 (.mobileconfig) Linux / Firefox：下载 PEM (.crt) Android / Windows：下载 DER (.der)

iOS / iPadOS

  1. 用 Safari 打开本页并下载描述文件，选择“允许”。
  2. 设置 → 通用 → VPN 与设备管理 → 安装“kdae local CA”。
  3. 设置 → 通用 → 关于本机 → 证书信任设置 → 打开“kdae local CA”的完全信任。

macOS

双击描述文件，在“系统设置 → 隐私与安全性 → 描述文件”中安装；或在“钥匙串访问”中将证书设为“始终信任”。

说明

如果路由器的 IP 或主机名变化，运行 kdae-ui-cert 重新签发叶子证书；根证书不变，无需重新安装。不想安装证书时，可改用 HTTP 访问（局域网内），面板同样可用，仅少了离线缓存。
